## Experiment 3: gradient boosting

**Question:** Can sequential shallow trees improve on the existing forest while holding features and preprocessing fixed?

Use the existing numeric passenger attributes plus FamilySize, IsAlone, and grouped Title. Numeric columns receive training medians and scaling; categorical columns receive training modes and one-hot encoding. PassengerId and raw Name, Cabin, and Ticket are excluded from model inputs.

Fixed settings: 200 boosting stages, learning rate 0.05, random state 42. Search four configurations, ranked only by development CV accuracy:

| Maximum depth | Minimum samples per leaf | Mean CV accuracy | Fold standard deviation |
| --- | --- | --- | --- |
| 2 | 5 | 0.8062 | 0.0113 |
| 2 | 10 | 0.8118 | 0.0194 |
| 3 | 5 | 0.8216 | 0.0267 |
| 3 | 10 | **0.8287** | 0.0210 |

**Conclusion:** the selected configuration is 0.42 percentage points below the forest's mean CV accuracy and also lower on the reused holdout. This experiment does not justify replacing random forest as the current CV leader. The Kaggle upload scored **0.76315**, which is 1.436 percentage points below the historical forest score of 0.77751. The result supports retaining the forest as our leading approach. This comparison includes differences between the historical and cleaned preprocessing; it does not isolate the model algorithm alone.

## Experiment 4: random forest parameter search

**Retained in the final report:** this experiment demonstrates a controlled search over two hyperparameters and analysis of overfitting. Its outcome is that none of the tested alternatives improved the cleaned control. The successful upload establishes the cleaned pipeline's Kaggle score. Present it concisely as a tuning experiment with a negative result; it adds evidence for model selection, but does not add a new model family.

**Question:** Can depth and minimum leaf size improve the forest while keeping features and preprocessing fixed?

We predeclared nine configurations: maximum depth 5, 8, or unlimited; minimum leaf size 5, 3, or 1. Each forest has 200 trees and seed 42, with all other defaults unchanged. We used the same five development folds as the cleaned baseline and fitted preprocessing separately inside each fold. The depth-5/leaf-1 control reproduced all five original fold scores exactly.

Selection rule: highest mean development CV accuracy; exact ties favor the first setting in grid order (shallower depth, then larger leaves). Neither training accuracy, holdout accuracy, nor Kaggle scores select the configuration. No extra search was added after the result.

| Maximum depth | Minimum leaf size | Mean training accuracy | Mean CV accuracy | Fold standard deviation |
| --- | --- | --- | --- | --- |
| 5 | 5 | 0.8416 | 0.8259 | 0.0252 |
| 5 | 3 | 0.8469 | 0.8287 | 0.0241 |
| 5 | 1 | 0.8473 | 0.8329 | 0.0231 |
| 8 | 5 | 0.8648 | 0.8216 | 0.0185 |
| 8 | 3 | 0.8806 | 0.8189 | 0.0230 |
| 8 | 1 | 0.9273 | 0.8160 | 0.0202 |
| Unlimited | 5 | 0.8634 | 0.8202 | 0.0158 |
| Unlimited | 3 | 0.8901 | 0.8217 | 0.0226 |
| Unlimited | 1 | 0.9838 | 0.7978 | 0.0101 |

**Result:** the depth-5/leaf-1 control remains best at **0.8329 mean CV accuracy** (fold standard deviation **0.0231**), with **0.8324** on the reused holdout. The unlimited-depth/leaf-1 model reaches 0.9838 training accuracy but only 0.7978 CV accuracy, consistent with overfitting. Tuning did not improve this control. The CV score is a development estimate, not an unbiased final performance estimate.

The selected model produces **exactly the same predictions as `submission_forest_clean.csv`**. We keep those settings rather than force a different, worse configuration. This is the cleaned pipeline prepared after checkpoint 2; the old Kaggle forest used different preprocessing. Its original uploaded CSV is not preserved in the repo, so we cannot compare individual predictions directly. Submission 4 now has its own observed Kaggle score: **0.77511**, which is 0.240 percentage points below the historical forest and 1.196 percentage points above gradient boosting. This is not a controlled estimate of the preprocessing effect on generalization.
